# Contributing / Katkı Rehberi

Thanks for helping improve Repo First Aid.

Türkçe: Repo First Aid'i geliştirmeye yardımcı olduğun için teşekkürler.

## Development / Geliştirme

1. Create a focused branch. / Amacı net bir branch oluştur.
2. Run the test suite. / Test paketini çalıştır:

   ```bash
   python -m unittest discover -s tests -v
   ```

3. Keep changes dependency-free unless there is a clear reason to add a dependency. / Açık bir gerekçe olmadıkça bağımlılık ekleme.
4. Add or update tests for behavior changes. / Davranış değişiklikleri için test ekle veya güncelle.
5. Open a pull request with a short explanation and test output. / Kısa açıklama ve test çıktısıyla pull request aç.
